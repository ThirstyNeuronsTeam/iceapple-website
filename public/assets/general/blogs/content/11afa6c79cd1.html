Quick Overview

Let’s get into the paddle OCR !! If you are reading this article then you have heard about the OCR. If not don’t worry !! I will give you a short description. The OCR is an acronym which stands for Optical Character Recognition. It means the reading or recognition of textual data from the visual information such as Image. Simply, It is the process of retrieving the text from the image data.

For the OCR process, we previously used different image processing techniques. The later arrival of machine learning and deep learning models enhanced the field of OCR with much more accuracy. Paddle Paddle is one among the deep learning framework. Yes, the paddle is not a single model it consists of different models pre trained for different characteristics of Image data.

Paddle Architecture

Parallel Distributed Deep Learning, shortly known as Paddle, is developed by Baidu Research. The Paddle Paddle framework is written in Python and C++. Paddle Paddle OCR (PPOCR) framework is a two stage OCR system which consists of Detection and Recognition. In Between Text direction classifiers are used. In Other Words, the PPOCR provides us with three highly pretrained model types such as Text Detection, Text Direction Classifier and Text Recognition. Currently PPOCRv3 is a highly used ultra lightweight model and also effective in producing high accuracy results.

Image ref: https://github.com/PaddlePaddle/PaddleOCR/blob/main/doc/doc_en/ppocr_introduction_en.md

Paddle Paddle framework comes with a multi layered pipeline consisting of filters with blackboard algorithms & models in each layer. The fig 1.1 describes the PPOCR v3 architecture which consists of Text Detection ,Detection boxes Rectify and Text Recognition are blackboard containers which consist of different algorithms. The containers are connected through a pipeline and pass the filtered data to the next layer.

Here in fig 1.1, the blackboard containers is represented by Text Detection, Detection Boxes Rectify and Text Recognition. Because under these parts we have multiple algorithms and models available among them based on the data, different algorithms are applied to provide more efficient results. The blackboard mechanism is used to apply multiple algorithms to address the problem to get better results.

Mainly PPOCR v3 Text Detection is trained on DB (Differentiable Binarization) algorithm trained in MobileNetV3 model using distillation strategy. Text Recognition is trained on SVTR_LC Net (SVTR: Scene Text Recognition with a Single Visual Model + LC Net — Lightweight Counting Network).

We have used the PPOCRv3 in one of our projects. From our findings , PPOCR v3 has more accuracy than other open source models available. PPOCR v3 is a stable model and provides high performance on most of the image data. But even PPOCR v3 struggles to retrieve text data from the images of gaming UI slot machines.

The Paddle Paddle framework provides us with different model types for inference and training. As you can see from the fig 1.3 , paddle paddle framework offers us different models. For training , we need to pass the configuration file with specific values on model name, model hyper parameters value. The configuration file and base pretrained model can be obtained from the models_list file from the PPOCR github.

For training , paddle paddle framework requires three major components such as .pdopt, .pdparams and .states. These components are trained based on the configuration parameters and input image dataset. After training ,we need to transform the model to a different format for performance efficiency. The previous components take more space and more time to compute. The paddle paddle framework offers us the transformation script to use it in the inference stage. The transformed components are .pd model and .pdiparams. The last transformation is optional depending on your use case and where you are deploying the model. The model is optimized to different formats such as .nb which is a very lightweight model.

The paddle paddle framework also offers us the way to transform the inference model components to onnx type. The onnx model’s primary purpose is to facilitate seamless exchange and sharing of models across different deep learning frameworks.

def get_mini_boxes(contour):
  print(f"The contour : {contour.shape}  \n")
  bounding_box = cv2.minAreaRect(contour)
  #cv2.minAreaRect(contour) computes the smallest (in terms of area) rotated rectangle that can contain the contour.
  #The function returns a rotated rectangle which is described by a tuple of three elements:
  #1. Center (x, y): The center point of the rectangle.2. (width, height): The dimensions of the rectangle.3. Angle of rotation: The angle the rectangle is rotated.
  print(f"The bounding box : {bounding_box} \n ")
  points = sorted(list(cv2.boxPoints(bounding_box)),key=lambda x: x[0]) #four edge points of the rectangle  shape (4,2)
  print(f"the box points  : {points} \n ")
  index_1, index_2, index_3, index_4 = 0, 1, 2, 3
  if points[1][1] > points[0][1]:
      index_1 = 0
      index_4 = 1
  else:
      index_1 = 1
      index_4 = 0
  if points[3][1] > points[2][1]:
      index_2 = 2
      index_3 = 3
  else:
      index_2 = 3
      index_3 = 2
  boxPoints = [
            points[index_1], points[index_2], points[index_3], points[index_4]
        ]

  print(f"the bbox : {bounding_box[1]} min value is : {min(bounding_box[1])} \n ")
  print(f"the box points after sorting : {boxPoints} \n \n")
  return boxPoints,min(bounding_box[1])

def box_score_fast(Bitmap, _box):
  '''
        box_score_fast: use bbox mean score as the mean score
  '''
  h, w = Bitmap.shape[:2]
  box = _box.copy()
  xmin = np.clip(np.floor(box[:, 0].min()).astype("int32"), 0, w - 1)
  xmax = np.clip(np.ceil(box[:, 0].max()).astype("int32"), 0, w - 1)
  ymin = np.clip(np.floor(box[:, 1].min()).astype("int32"), 0, h - 1)
  ymax = np.clip(np.ceil(box[:, 1].max()).astype("int32"), 0, h - 1)
  maskf = np.zeros((ymax - ymin + 1, xmax - xmin + 1), dtype=np.uint8)
  box[:, 0] = box[:, 0] - xmin
  box[:, 1] = box[:, 1] - ymin
  cv2.fillPoly(maskf, box.reshape(1, -1, 2).astype("int32"), 1)
  mean = cv2.mean(Bitmap[ymin:ymax + 1, xmin:xmax + 1], maskf)
  print(f"The mean is {mean}")
  return mean[0]

The above code snippet describes the process of detection boxes vertices points for each contours. First, get mini boxes function will be invoked to get the box points of the detection area from the contour. Next, Box Score fast function is called to box score which is mean value of box area. we filter the small box area. Then the unclip function is called which expands the margin of the detection boxes to fit the detected text. Here again minimum side of the box is calculated based on mean and if the box side is less than threshold the box is filtered out.

Now, the box size is adjusted according to the original image size. Since previously we have taken copy of the original image passed and done image processing on it. The boxes are appended to the boxes list which is the vertex points of the text detected area. These vertex points are used to crop the original image in next stage. Then the list of cropped images are sent to the Text Direction Classifier and Text Recognition.

This dataset focused on sales KPI; we need to be more specific about which KPI is needed based on the requirements in real time. Here I took a few KPI and created formulas and used a pivot table to derive the insights.

  • Average Profit Margin = (Net Income/Net Sales) *100.
  • Total Selling Value = (Quantity *Sales) * (1-discount)

Apart from this, there were many effective KPI’s there. With this dataset, we derived the values from the data and created the sales dashboard based on the category, segment, year, month, region- wise, market and the shipping mode.

I have renamed the datasets as “Master Data” and added a new column and derived the total selling value with the formula as mentioned. Ignore if you don’t have a discounted value in the datasets.

Created a new sheet as Analysis, to capture all the analysis in a single sheet. I have used pivot tables to get the necessary details. Even if you change the value in any field, it will automatically update on the dashboard. The number of orders, total selling value, profit sum is calculated using the pivot table and the same has been referenced in the dashboard.

In this dataset, we have 3 important fields which give the majority of the insights for this sales dataset.

  • Category
  • Segment
  • Year- Month

To get the dynamic view on the dashboard, Slicers are the best option in excel.

Slicer Creation

  • Create a Pivot table for the total selling value based on the category
  • Select the pivot table>insert >Slicer >and select the category

This shows as mentioned above, you can modify the is slider design or you can create a new slicer design and adjust it as per your choice.

I have created 4 slicers with the fields mentioned above and linked the relationship to each other with all the charts to get the dynamic data. To give a relationship,

Click on the Category Slicer > Go to slicer tab> Report Connections>Click the check box on the pivot table where you need to establish the connection.

I have used the vertical/horizontal bar, pie charts, tree map for the visualization to show the sales value based on the fields.

Insights:

This supermarket received 51,290 orders in 4 years from 2012 -2015. Based on the category, technology provided major sales and Asia Asian Pacific sales were 32% and the lowest sales market was Africa. Standard and second class are the top 2 shipping modes which provide the major revenue from shipping mode. The Western Europe region has a more sales market and the southern Asia region is the least. The top customers are consumers, and the second largest is corporate companies.
